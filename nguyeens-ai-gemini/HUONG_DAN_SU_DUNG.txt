========================================================================
     NGUYEN'S AI — GEMINI EDITION (WINDOWS AUTOMATION)
========================================================================

1. OVERVIEW:
   Nguyen's AI is a lightweight local Windows desktop automation assistant
   powered by Google Gemini 3.5 Flash Vision, operating at 10 FPS with continuous
   optical reasoning, physical cursor glide, and native keyboard output.

2. INTERFACE & KEYBOARD OUTPUT:
   - Full interface, command prompt, logs, and settings are in English.
   - Keyboard typing output exclusively supports Vietnamese with full Unicode diacritics
     ("tiếng Việt có dấu đầy đủ") without using the system clipboard.

3. QUICK START:
   - Double-click 'run.bat' for Command Prompt mode.
   - Or double-click 'web.bat' for local Web GUI mode (http://127.0.0.1:8765).
   - Enter your Gemini API key (encrypted with Windows DPAPI).
   - Type your task and press ENTER.

4. EMERGENCY STOP:
   - Press [Ctrl + Fn + E] (or Ctrl + E) at any time.
   - Or push the mouse into the top-left corner (0, 0).
